# Trackerrr

Pití, suplementy a recenze jídla na jednom místě. Webová aplikace (PWA) na plochu telefonu, funguje i offline.

## Co umí
- **Přehled**: týden s kroužky pití (tečky = suplementy / 3 jídla splněné), série dní 🔥, kapka s očima, rychlé pití jedním ťuknutím, další dávka suplementu s tlačítkem Vzít
- **Pití**: vlastní nápoje (Nastavení), vlastní objem, „napřed / pozadu“ podle času, smazání se Zpět
- **Suplementy**: libovolné časy dávek, zpožděné dávky svítí, úprava a mazání
- **Jídlo**: kategorie podle času, nejčastější podniky jako čipy, úprava záznamu, historie s hledáním a žebříček podniků
- **Statistiky**: týden / měsíc, průměr, splněné dny, série, suplementy po jednotlivých
- **Cloud**: kód místnosti → stejná data na více zařízeních (Google Apps Script), export / import zálohy

## Spuštění lokálně
`npx -y http-server . -p 5191 -c-1`
